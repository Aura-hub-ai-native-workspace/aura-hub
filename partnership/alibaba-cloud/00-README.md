## A note on honesty, on purpose

Every document in this package was written against the actual, checkable
state of the repository at the time of writing: 11 real provider
adapters, a real live 401 from the real DashScope endpoint, a repo
created 2026-07-28 with a single maintainer, 0 stars/forks, work
unmerged to `main`, no hosted demo, no captured screenshots. Nothing here
claims traction, users, or maturity the project doesn't have. If any of
these facts change before you send this package, update the relevant
numbers before sending — don't let this package go stale and
accidentally overclaim.
