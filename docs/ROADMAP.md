# AURA Roadmap (execution detail)

> For the current high-level direction (Now / Next / Future), see the
> root [`ROADMAP.md`](../ROADMAP.md). This file is the execution-level
> history and tracking detail behind it.

## History

The `AURA Presentation v0.1` milestone (application shell, design
system, project workspace sections, workflow editor/library, knowledge
graph visualization) shipped and closed. Since then the platform has
grown well beyond that initial scope — Mission Control's v3 execution
engine, the Engineering Governance, Predictive Engineering, and
Engineering Memory platforms, the automation engine, and the hardened
multi-provider AI runtime all landed after v0.1. See
[`docs/architecture/`](architecture/) for what each of those actually
does, and the root [`ROADMAP.md`](../ROADMAP.md) for what's next.

## How this roadmap is maintained

- The repository owner updates this file when milestone scope changes.
- Issues/PRs targeting a specific milestone are labeled and assigned to
  that milestone.
- Anything not required for the current milestone belongs in `Backlog`
  on the [AURA Development project board](PROJECT_BOARD.md).
