# AURA Hub — Physical Engineering Foundation

This directory contains the research, architecture decisions, and documentation
for AURA Hub's Physical Engineering Orchestration Workspace extension.

## Structure

```
docs/physical-engineering/
├── README.md                    # This file
├── architecture/                # Architecture specifications
├── research/                    # Research ledger (tool findings, API discoveries)
├── decisions/                   # Architecture Decision Records (ADRs)
├── integrations/                # Tool integration specs
├── schemas/                     # Data model schemas
├── workflows/                   # Engineering workflow definitions
├── experiments/                 # Experimental results
├── compatibility/               # Cross-platform compatibility data
├── risks/                       # Risk assessments
├── validation/                  # Validation test plans
└── build-log/                   # Build reports and status
```

## Key Principle

**AURA is the orchestration layer, NOT the engineering tool.**

AURA connects AI agents with existing engineering tools through governed
capabilities. It does not replace CAD, EDA, simulation, or IDE applications.
